# Preview Issue Severity

## P0

Security or integrity failure with immediate stop: secret or source leak, approval bypass, data overwrite, cross-project/process access, unsafe action, or unrecoverable ledger/update state. Stop the pilot and keep the sample.

## P1

Release-blocking failure that can mislead or prevent safe use: incorrect phase/action/pending-decision display, pause or recovery unavailable, evidence sequence mismatch, telemetry/privacy consent violation, or a signed update accepted outside its policy. Do not expand the preview.

## P2

Non-blocking usability or presentation defect with a safe workaround. Record it with a redacted description and do not change the original sample when retesting.
