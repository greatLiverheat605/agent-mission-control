# Preview Consent And Privacy

Participation is voluntary. The participant may stop at any time, and stopping does not remove the local evidence needed to explain a failed run. The study records only a pseudonymous participant ID, task outcome, elapsed times, project type, hardware profile, redacted issue severity and hashes of local evidence files.

Telemetry is off by default and remains local. No source code, prompts, hidden reasoning, provider payload, credentials, cookies, headers, file contents or network identifiers are collected. An export is never automatic: the participant must review the redacted preview and actively confirm the export action. The preview shows categories, sizes and hashes rather than raw content.

If a participant enables telemetry or requests an export, the UI records that explicit consent beside the local receipt. Turning telemetry off stops future collection; it does not silently delete an existing failed sample. Study operators must keep the original receipt and use a new output path for any corrected analysis.
