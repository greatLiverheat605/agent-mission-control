# Bundled Font Licenses

The application bundles the following npm-distributed font files at build time:

- IBM Plex Sans Variable, package `@fontsource-variable/ibm-plex-sans`, SIL Open Font License 1.1.
- IBM Plex Mono, package `@fontsource/ibm-plex-mono`, SIL Open Font License 1.1.

Fontsource package metadata and the complete license texts remain included in the installed package artifacts. No remote font request is made at runtime.
